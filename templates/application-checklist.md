# Application Quality Checklist

## Compliance
- [ ] Prompt answered
- [ ] Word/page limits met
- [ ] Required sections/documents included
- [ ] Format and file names comply
- [ ] Deadline and time zone verified

## Accuracy
- [ ] Dates and degree names consistent
- [ ] Grades match official records
- [ ] Experience and project claims supported
- [ ] Publication status accurate
- [ ] References verified
- [ ] Links work
- [ ] No invented claims

## Writing and fit
- [ ] Clear opening and purpose
- [ ] Claims supported with examples
- [ ] Research interests coherent
- [ ] Program fit specific and verified
- [ ] Goals realistic
- [ ] Documents complement each other
- [ ] No repetitive or generic wording
- [ ] Applicant's authentic voice retained

## Final
- [ ] Applicant reviewed and approved
- [ ] Institution's AI-use rules checked
- [ ] Final PDFs/files checked after export
