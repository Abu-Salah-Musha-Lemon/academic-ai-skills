# Security policy

## Scope
This repository contains prompt/instruction files and templates. It does not currently ship executable product code, but issues involving unsafe instructions, privacy risks, malicious links, or compromised release files are in scope.

## Reporting
Please do not publish sensitive security details in a public issue. Use GitHub's private vulnerability reporting feature if enabled for this repository, or contact the maintainers through the email/address listed in the repository profile. Include steps to reproduce, impact, and affected files if safe.

## Response
Maintainers will acknowledge reports when able, assess impact, and coordinate a fix and disclosure. No response-time SLA is currently promised.
