# Changelog

All notable changes to this project are recorded here.

## [0.0.1] - 2026-11-26

Initial pre-1.0.0 release of the Academic AI Skills collection.

- Includes 13 reusable skills for academic research, scholarly writing, and graduate applications.
- Includes seven intake, planning, and research templates.
- Adds installation, testing, contribution, security, and release documentation.
- Adds static validation, behavioral evaluation cases, and GitHub Actions CI.
- Establishes project authorship, MIT licensing, and citation metadata.
- Model-based runtime evaluation is not claimed; see `docs/TESTING.md`.
