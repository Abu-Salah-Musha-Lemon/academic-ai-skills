# Contributing

Thank you for helping improve these skills. Contributions should improve accuracy, usefulness, accessibility, or writing quality for a broad international audience.

## Before opening an issue
- Search existing issues and discussions.
- Describe the skill, task, expected behavior, and observed problem.
- Include a sanitized example. Do not upload private applicant documents.

## Pull requests
- Keep changes focused.
- Follow the Agent Skills format and existing conventions.
- Avoid adding country-, institution-, or user-specific assumptions to universal skills.
- Add or update tests and behavioral evaluation cases when changing instructions.
- Verify factual claims and link primary/official sources when relevant.
- Preserve ethical guardrails and the natural-writing standards.
- Explain the reason for the change and any limitations.

## Local checks
```bash
python tests/run_static_tests.py
```

## Style
- Markdown, concise headings, direct instructions.
- Examples should use synthetic data and be clearly labelled.
- Do not add dependencies without justification.
- Do not claim real-model evaluation without reproducible evidence.
