# Contributor Code of Conduct

We are committed to a welcoming, respectful, and constructive community.

Expected behavior: be respectful; assume good faith while addressing harmful behavior; provide actionable feedback; respect privacy; and keep discussions focused on improving the project.

Unacceptable behavior includes harassment, discrimination, threats, personal attacks, doxxing, sexualized attention, and deliberately disruptive conduct.

Project maintainers may remove content or restrict participation when needed to protect the community. Report conduct concerns privately to the repository maintainers using the contact method listed in the repository profile.

This code of conduct is adapted in spirit from the Contributor Covenant.
