# Quality Assurance and Skill Testing

## CV Quality Review

Check: - Completeness against the target. - Factual accuracy and
evidence. - Chronology and cross-section consistency. - Publication
status and authorship. - Individual project contribution. - Grammar,
clarity, and repetition. - Formatting, page limit, file type, links, and
parsing. - Unsupported or exaggerated claims.

## Issue Severity

-   Critical: false or materially misleading claims, fabricated
    credentials/publications, serious eligibility misrepresentation, or
    violation of an explicit mandatory submission requirement.
-   Major: material date/status conflicts, missing required information,
    unsupported performance claims, or significant parsing/document
    problems.
-   Minor: punctuation, small spacing, or non-material style
    inconsistencies.

Severity depends on context. An unverified metric should be withheld
from the CV and investigated; it is not automatically a minor issue.
Intentional fabrication is critical.

## Readiness

-   Ready: required checks pass and no material unresolved issue
    remains.
-   Needs Revision: correctable issues remain.
-   Needs User Input: important facts need confirmation.
-   Blocked: a required dependency or source is unavailable.

## Revalidation

After changes, recheck affected sections and ensure corrections did not
introduce new inconsistencies.

## Skill Testing

Use: 1. Functional tests: create, review, tailor, audit, and roadmap
tasks. 2. Knowledge tests: CV types, publication status, requirements,
project evidence. 3. Instruction compliance: no fabrication, no
redundant questions, source use. 4. Edge cases: missing data, conflicts,
private repositories, no publication, inaccessible sources. 5.
Regression tests: changes do not break existing workflows.

Test with expected outcomes and record failures. Do not claim a skill
passed tests that were not run.
