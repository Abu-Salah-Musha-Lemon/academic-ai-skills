# Academic Profile & CV Assistant

Version: 1.0.0

This package extends the original Academic CV skill into a modular
academic profile, university research, portfolio, CV, and
career-development assistant.

Start with `SKILL.md`. It defines the core behavior and routes to
supporting modules. Load only the module needed for the current task.

The package does not guarantee admission, funding, publication,
employment, or ATS selection. All user claims and external requirements
must be supported by evidence or clearly marked as unverified.
